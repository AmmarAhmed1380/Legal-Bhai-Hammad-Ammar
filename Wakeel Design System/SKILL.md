Key brand rules:
- Primary daftar-green #0F6E56 on warm off-white canvas #F8F7F3. Accent terracotta #D85A30 is for conflicts/danger only — never decorative.
- Case numbers are always mono (JetBrains Mono). UI is Plus Jakarta Sans. Display is Source Serif 4. Urdu is Noto Nastaliq Urdu.
- Always label IHC data as Live and District data as Demo — never obscure the distinction.
- Lucide icons, 1.5px stroke, 22px on mobile tab bars. No emoji.
- Cards use 14–18px radii + `0 1px 2px rgba(44,44,42,.06), 0 10px 30px rgba(15,110,86,.05)`. Focus ring is 2px solid primary.
- Copy is professional, direct, lowercase on chips, sentence case everywhere else. English and Urdu Nastaliq for client-facing strings.
